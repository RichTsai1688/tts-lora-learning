# 語音 LoRA 入門：從資料到 Colab

這是一套繁體中文實作教材：使用經授權的單一說話者錄音，先建立及檢查資料集，再以 Qwen3-TTS 0.6B Base 訓練一個 LoRA 實驗。專案只包含程式與教材，不附錄音、逐字稿、模型權重或既有個人實驗資料。

## 學習路線

1. **建立資料庫**：[音色與語調／新語言的收集、分析與切分](docs/01-dataset.md)。學會確認授權、檢查錄音與文字、避免資料洩漏。
2. **訓練一個 LoRA**：[Colab 教學](docs/02-colab.md) 和 [訓練筆記本](colab/train_lora.ipynb)。從資料檢查、語音編碼、小量測試到訓練與評估。

音色可想成誰在說話，語調是說話方式，語言則是說什麼語言；它們可能互相影響，必須設計對照組。這份簡化訓練程式沒有獨立語調或語言控制功能，也不保證學會基礎模型未支援的語言。

## 使用 AI 助手的 Skill

將 `skills/tts-lora-workflow` 資料夾複製至你的 Codex skills 目錄（通常為 `~/.codex/skills/`），重新啟動或重新載入後，可要求助手依 `tts-lora-workflow` 協助本教材。請同時提供此專案路徑；Skill 導讀此專案的程式與文件，不包含模型或語料。

## 目錄

| 路徑 | 用途 |
| --- | --- |
| `scripts/dataset_tool.py` | 檢查資料並依錄音場次切分 |
| `examples/manifest.csv` | 欄位範例，不含實際音訊 |
| `training/` | Qwen3-TTS 資料編碼與單一語者 LoRA 訓練程式 |
| `colab/` | 可逐格執行的 Colab 筆記本 |
| `skills/` | 可重用的 Codex Skill |
| `docs/` | 教學與驗收方式 |

請只使用說話者同意且用途獲授權的資料。聲音本身可能識別個人，公開前應移除私人資料、音訊、逐字稿、權重、憑證及內部路徑；`.gitignore` 只是輔助，不能取代檢查。
