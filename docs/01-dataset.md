# 第一課：建立語音資料庫

## 先決定問題與取得授權

- **音色與語調**：選一位同意提供聲音的說話者，錄製不同句子與自然、開心等想比較的語調。這份教材的訓練程式沒有語調控制開關；混合語調可能使生成語氣混合，應先做單一語調基準，再分開比較。
- **加入語言**：同一位說話者錄目標語言，並保留原語言資料做比較。先確認基礎模型對該語言的支援；對未支援語言只能視為探索，無法保證成功。此簡化訓練程式不使用 language 欄位當語言控制 token。

確認錄音者明確同意訓練及預定使用方式，來源及授權留在私人紀錄。錄音與逐字稿可能含人名、地點、聯絡方式等，建立資料前先去識別化；聲音本身仍可能識別說話者。不要把真實資料或衍生模型放入公開專案。

## 資料格式

將每個句子存為一個 **24 kHz、單聲道、PCM WAV**，保留人工校對逐字稿。原始檔保留不動；以下示例從複本轉換，需要本機安裝 ffmpeg：

```bash
ffmpeg -i input.wav -ac 1 -ar 24000 -c:a pcm_s16le output.wav
```

建立 UTF-8 CSV，欄位與 [範例](../examples/manifest.csv) 相同：`audio` 為相對 CSV 的路徑；`text` 與音訊一致；`language` 和 `style` 為統計標籤；`group` 為獨立錄音場次或來源。相同原始錄音的片段及其衍生版本要有同一 group，避免切到不同集合。範例只有欄位示意，沒有附音檔。

另準備一段與所有資料片段不同的、同一說話者乾淨參考錄音，建議約 5–10 秒。工具檢查是否與資料檔完全相同，但無法偵測同一原始音訊的裁切或語意重複；請人工確認來源獨立。

```bash
python scripts/dataset_tool.py /path/to/manifest.csv
python scripts/dataset_tool.py /path/to/manifest.csv --ref-audio /path/to/reference.wav --output /path/to/new-splits --seed 42
```

工具檢查檔案、格式與完全重複的音訊，報告筆數、時數、語言及語調分布，並按 group 分 train / val / test。至少三組；比例按 group 而不是片段數計算，小資料集可能不均衡，也不保證每個語言或語調都涵蓋三組。檢查報告後，人工核對各組分布、文字、雜音、斷字、重複句與素材授權。1–15 秒只是待複核提示，不是品質認證。測試集不要參與訓練或選模。

JSONL 內含逐字稿與絕對路徑，屬私有資料，應在實際訓練環境重新產生。資料標籤、資料筆數、時數不代表音質；請固定測試句、盲聽比較可懂度、音色與語氣，並檢查原語言是否退步。
